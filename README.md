# Magic Door - Виртуальная дверь в несуществующем мире

Интерактивный веб-проект с виртуальной дверью, которая открывает портал в магический мир.

## Описание

Этот проект представляет собой интерактивную веб-страницу с виртуальной дверью, которая создает захватывающий визуальный опыт. При клике на дверь открывается портал с анимированными эффектами и интерактивными элементами.

## Особенности

- 🚪 Интерактивная виртуальная дверь с 3D эффектами
- ✨ Анимированные переходы и визуальные эффекты
- 🎨 Современный дизайн с градиентами и тенями
- 📱 Адаптивный дизайн для всех устройств
- 🎭 Интерактивные элементы и анимации

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, анимации)
- Vanilla JavaScript
- Современные CSS эффекты (backdrop-filter, box-shadow)

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/RyBra/magic.git
```

2. Откройте файл `index.html` в браузере

Или запустите локальный сервер:
```bash
# Используя Python
python -m http.server 8000

# Используя Node.js
npx http-server
```

## Структура проекта

```
magic/
```

## Использование

1. Откройте страницу в браузере
2. Нажмите на кнопку "Нажми меня" для базовой интерактивности
3. Взаимодействуйте с виртуальной дверью для полного опыта
